**Prompt 1: Splits a number list into an expression tree and computes its exact integer value**
In g12_q2.pl, implement build_expr(Nums, Val, Tree) that splits a non-empty list of non-negative integers Nums into an expression tree (num(N) or op(Op, Left, Right) for +, -, *, /) preserving number order without concatenating digits or using unary minus, and evaluates its integer value Val. Enforce exact integer division at every / node (RVal =\= 0, 0 =:= LVal mod RVal, Val is LVal // RVal). Intermediate values may be negative. Do not use string parsing or dynamic predicates.

**Prompt 2: Canonical string formatter**

In g12_q2.pl, implement format_expr(Tree, Str) to convert an expression tree (num(N) or op(Op, Left, Right)) into a canonical SWI-Prolog string (string, not atom or code list) with no spaces. Follow these rules: * and / have higher precedence than + and -; operators are left-associative; wrap Left in parentheses only if its top operator has strictly lower precedence than Op; wrap Right in parentheses if its top operator has lower or equal precedence to Op; never wrap single numbers.

**Prompt 3: Single equation generator**

In g12_q2.pl, implement generate_equation(List, Equation) which splits List (length >= 2) into two non-empty parts LeftNums and RightNums, builds expressions for both sides with the exact same integer value using build_expr/3, formats both sides via format_expr/2, and joins them with "=" into an SWI-Prolog string Equation. For lists of length 0 or 1, or when no valid equation exists, it must cleanly fail without looping or throwing errors.

**Prompt 4: All equations and counter**

In g12_q2.pl, implement all_equations(List, Equations) and count_equations(List, N). all_equations/2 should find all valid canonical equation strings for List using findall/3 and sort/deduplicate them using sort/2 (returning [] when none exist). count_equations(List, N) should unify N with the length of Equations. Ensure no printing or side effects occur

**Prompt 5: Test file**

Create tests/test_q2.pl consulting ../code/g12_q2.pl to test generate_equation/2, all_equations/2, and count_equations/2. Include all assignment examples ([4,2,5,3], [2,3,4], [2,4,8]) plus edge cases: empty list [], single-element list [5], zeros (division by zero rejection), non-exact division rejection, negative intermediate results, and parenthesization of same-precedence right operands like 1-(2-3) vs 1-2-3
