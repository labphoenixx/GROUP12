**Prompt 1: Splits a number list into an expression tree and computes its exact integer value**
In g12_q2.pl, implement build_expr(Nums, Val, Tree) that splits a non-empty list of non-negative integers Nums into an expression tree (num(N) or op(Op, Left, Right) for +, -, *, /) preserving number order without concatenating digits or using unary minus, and evaluates its integer value Val. Enforce exact integer division at every / node (RVal =\= 0, 0 =:= LVal mod RVal, Val is LVal // RVal). Intermediate values may be negative. Do not use string parsing or dynamic predicates.
