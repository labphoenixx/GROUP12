**Prompt 1: Tail-Recursive List Helpers**

In g12_q4.rkt, start with #lang racket/base and implement tail-recursive my-reverse, my-length, and my-map using accumulators and only the allowed built-ins (define, let, if, null?, pair?, cons, car, cdr, +, '()). Hidden tests use lists of 10,000 elements, so iterative/tail-recursive implementation is required to avoid stack overflow. Do not use built-in length, map, or reverse.

**Prompt 2: Higher-Order Inserter**

In g12_q4.rkt, define (make-inserter x len-ok?) using only allowed built-ins and my-length/my-map. It must return a function taking a list lst that inserts atom x at the front of lst and every nested sublist whose original length (measured before insertion) satisfies (len-ok? len). Empty lists '() have length 0 and must also get x inserted if (len-ok? 0) is true. Handle nesting depth 100 cleanly.


**Prompt 3: Conditional Inserter**

In g12_q4.rkt, define (insert-if-short x lst n) using make-inserter so that x is inserted at the front of every list at every nesting level whose original length is strictly less than n ((< len n)). Ensure insert-if-short has only this single definition in the file and uses no forbidden built-ins.

**Prompt 4: Standard Input/Output Wrapper**

In g12_q4.rkt, define (print-insert-result) taking zero arguments. Using read, read x, lst, and n in that exact order from standard input, compute (insert-if-short x lst n), and print the resulting list using display followed by newline. Do not print any prompts or extra text, and do not add top-level calls when the file is loaded.

**Prompt 5: Test File**

Create tests/test_q4.rkt to test my-length, my-map, make-inserter, insert-if-short, and print-insert-result. Verify all four assignment examples, empty top-level lists with n = 0 and n = 3, a nested list of depth 100, and a flat list of 10,000 elements to confirm no stack overflow or timeout occurs.
