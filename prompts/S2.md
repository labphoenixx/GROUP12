**Prompt 1: Tail-Recursive List Helpers**

In g12_q4.rkt, start with #lang racket/base and implement tail-recursive my-reverse, my-length, and my-map using accumulators and only the allowed built-ins (define, let, if, null?, pair?, cons, car, cdr, +, '()). Hidden tests use lists of 10,000 elements, so iterative/tail-recursive implementation is required to avoid stack overflow. Do not use built-in length, map, or reverse.
