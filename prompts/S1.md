**Prompt 1: List helpers**

In g12_q3.rkt, start with #lang racket/base and write helper functions my-reverse (tail-recursive using an accumulator) and my-append using only the allowed built-ins (define, lambda, let, if, cond, null?, cons, car, cdr, '()). Do not use built-in append or reverse, and do not add top-level calls or display statements.

**Prompt 2: Inorder traversal**

In g12_q3.rkt, write a helper inorder that returns a list of node values in (left, node, right) order for a binary tree represented as '() or (value left right), using only allowed built-ins and my-append. Then define (print-inorder tree) which prints that list on one line with display followed by newline. Do not add top-level test calls.

**Prompt 3: All Traversals**

In g12_q3.rkt, write helpers preorder ((node, left, right)) and postorder ((left, right, node)) using only allowed built-ins and my-append. Then define (print-all-traversals tree) which prints three lines using display and newline: the inorder list, the preorder list, and the postorder list. For '(), print () on all three lines.

**Prompt 4: Height and Leaf Count**

In g12_q3.rkt, define (print-height-and-leaves tree) using only allowed built-ins. Compute the tree's height (0 for '(), 1 + (max left-height right-height) otherwise) and leaf count (0 for '(), 1 if both subtrees are '(), else sum of subtree leaves). Print the two-element list (list height leaves) on one line using display followed by newline.


**Prompt 5: Test File**

Create tests/test_q3.rkt using #lang racket/base to test print-inorder, print-all-traversals, and print-height-and-leaves on t1, t2, t3 from the assignment PDF, the empty tree '(), a single-node tree, and skewed trees (without modifying id_q3.rkt to use provide).
